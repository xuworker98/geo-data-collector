给 AI 用的速查参考。接口行为结论来自实测；商务、法规以官方条款为准。

## 一、坐标系与转换链路

| 源 | 原始坐标系 | 转 WGS84 的链路 | 坑 |
|---|---|---|---|
| 天地图 | CGCS2000 | pyproj EPSG:4490 → 4326 严格转换 | 与 WGS84 差异在厘米级，可近似等同，但**必须走严格转换** |
| 高德 | GCJ-02 | **迭代逆解 6 次** | 必须迭代逆解（往返误差 <1 m）；单次近似不可接受 |
| 腾讯 | GCJ-02 | 迭代逆解 6 次 | 同高德 |
| 百度 | BD-09 | BD-09 → GCJ-02 → WGS84 两级 | 只做一级会残留约 100 m |

> 南宁一带实测：GCJ-02 相对 WGS84 总偏移约 **560 m**（西约 477 m / 北约 292 m）。
> **绝不能把图商原始坐标当 WGS84 直接用。**

## 三、各源必踩的坑（按踩中频率排序）

### 1. 天地图逆地理参数写法（踩中率最高）
- 必须用 `postStr={'lon':x,'lat':y}&type=geocode`
- 写成 `ds={...}` 会被当成**正向**编码 → HTTP 400「keyWord 参数未填写」
- 曾因对 4xx 照样重试，每次白烧 6 s 退避，44 点共 **264 s**（占全套 64%）
- **配套铁律：4xx 是永久错，不重试**

### 2. 天地图 v2/search 的坐标字段
- 是 `lonlat` 字符串「116.1,39.9」，不是 geocoder 的 `lon`/`lat` 两个字段
- 写成 `p["lon"]` 会 KeyError 被引擎静默吞掉 → **整个天地图源假性失效**

### 3. 天地图服务端 Key 的 UA
- 带 Mozilla UA 直接报 **301013**
- 与民政部接口正相反：民政部**必须**带 Chrome UA，不带返回空数据

### 4. 高德 place 只查 POI 库
- 自然村在地名注记层，**place 查不到**，要查 inputtips
- 用户说"我在高德地图上明明看得到" ≠ API 能查到（网页搜索框走综合检索）

### 5. 高德日配额
- `10044 USER_DAILY_QUERY_OVER_LIMIT`
- **跨自然日不恢复** → 多半不是日配额，而是 Key 额度本身低或触发总量/并发限制
- 处置：换新账号 Key 比等待有效

### 6. 腾讯额度
- `status=121 此key每日调用量已达到上限`
- 广西政务 POI 实测常返回 0 条，覆盖质量差 → 熔断后不影响整体

### 7. 空间约束参数不可信
- 天地图 `mapBound` 实测**无效**（搜"沙江村"照样返回江西/湖南同名村），`specify` 直接 400
- 高德只有 `city`、百度只有 `region`，都是区县粒度
- **结论：空间约束必须在客户端自己做**（`spatial_gate_m`，默认 30 km 粗筛）

## 四、降级链与熔断

降级顺序**按任务类型不同**（`gc_common.TASK_ORDER`）：

```
政府驻地 / 行政区划：天地图 → 高德 → 百度 → 腾讯
POI / 门牌地址     ：高德 → 百度 → 天地图 → 腾讯
```

- 单源失效不中断，自动换下一个（配额耗尽、权限错误、网络异常均继续下一源）
- 日配额爆掉 → **当日熔断到次日 0 点**，已跑部分落盘，不空转重试
- 熔断状态是**进程内**的，重启进程清零
- 并发：每源默认 5、硬上限 10（`_DEF_PER_SRC` / `_MAX_PER_SRC`）；QPS 配置只用于限速与工期估算

## 五、合规与使用限制

| # | 事项 |
|---|---|
| 1 | **不内置 Key**：只存本地 `config.local.json`，绝不入源码/示例/日志；日志自动脱敏 |
| 2 | **不做 Key 池轮换**：多 Key 轮换突破配额属违规 |
| 3 | **输出坐标系**：工程交付 WGS84；对外发布地图建议 GCJ-02，并遵守审图号/资质要求（**转坐标 ≠ 合规**） |
| 4 | **商用授权**：费用与条款以各平台官网为准，商用前自行签约，本项目不代收不担保 |
| 5 | **数据二次分发**：采集结果不得作为数据源对外销售或对外提供服务 |
