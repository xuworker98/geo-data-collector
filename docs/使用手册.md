# 使用手册

> 面向**要跑一条完整任务的人**：装环境 → 配 Key → 准备区划 → 填模板 → 跑任务 → 解读输出。
> 面向 Agent 的执行纪律在 [`SKILL.md`](../SKILL.md)；判据与规则在
> [`references/`](../references/)；连不上、报错、乱码先看 [`排障与常见坑.md`](排障与常见坑.md)。

---

## 1. 环境与安装

| 依赖 | 版本 | 缺失时的行为 |
|---|---|---|
| Python | ≥ 3.10 | 无法运行（代码用了 `X \| None` 运行时注解） |
| pyproj | ≥ 3.4 | 自动降级为恒等转换（CGCS2000 与 WGS84 差异 <1 m） |
| openpyxl | ≥ 3.0 | 输出降级为纯标准库 `.xlsx` 或 CSV；**读取 `.xlsx` 输入不可用** |

```bash
git clone https://github.com/xuworker98/geo-data-collector.git
cd geo-data-collector
pip install -r requirements.txt
```

> 本工具**不做 Key 池、不需要数据库、不需要浏览器**，全部通过 HTTP 接口与本地缓存工作。

## 2. 配置 API Key

Key 读取优先级：**环境变量 > `config.local.json` > 空**。

```bash
copy config.example.json config.local.json    # Windows
cp config.example.json config.local.json      # macOS / Linux
```

编辑 `config.local.json`：

```json
{
  "keys": {
    "tianditu": "你的天地图Key",
    "amap": "你的高德Key",
    "baidu": "你的百度Key",
    "qq": "你的腾讯Key"
  }
}
```

或改用环境变量：`GDC_TD_KEY` / `GDC_AMAP_KEY` / `GDC_BAIDU_KEY` / `GDC_QQ_KEY`。

### Key 类型要求（最常见的踩坑）

| 源 | 申请地址 | 必须选的类型 |
|---|---|---|
| 天地图（主源） | https://console.tianditu.gov.cn/ | **Web 服务端** |
| 高德 | https://console.amap.com/dev/key/app | **Web 服务** |
| 百度 | https://lbsyun.baidu.com/apiconsole/key | **服务端** |
| 腾讯 | https://lbs.qq.com/dev/console/key/manage | **WebService** |

> 浏览器端 / JS API 类型的 Key 用不了，表现是「一直返回空或鉴权失败」。
> 只配一个源也能跑，但**单源是达标率头号杀手**（实测 1 源 55.6% vs 2 源 83.3%）。

### 合规

- **不内置 Key**，`config.local.json` 已被 `.gitignore` 排除
- **不做 Key 池轮换**（违规突破配额）
- 日志中 Key 一律脱敏（`mask_key()`）

## 3. 网络体检与能力自检

```bash
python scripts/config.py     # 网络体检：代理端口探测 + 四个站点可达性 + Key 配置
python scripts/gc_common.py  # 能力层自检：坐标往返误差 + 四源配置 + 天地图实连（有 Key 时）
```

网络体检输出示例（代理失效时）：

```
网络体检
--------------------------------------------------
  代理变量 : http://127.0.0.1:7960
  端口探测 : 不可用 → 已跳过
  实际出网 : 直连
  baidu    : HTTP 200 (0.15s)
```

**所有请求都超时时，第一步永远是跑这个，不要先怀疑 Key。**

## 4. 区划数据准备（零 Key）

区划名称与代码不依赖任何地图 Key：省/市/区县/乡镇取**民政部**国家地名信息库，
村/社区取**国家统计局**统计用区划代码。首次联网抓取后永久缓存到 `data/regions/`。

```bash
# 首次：联网抓取 + 自检（广西实测约 60~68 s）
python scripts/regions.py --province 广西 --check

# 之后：纯离线自检
python scripts/regions.py --selftest

# 完全无网环境的离线导入
python scripts/regions.py --import-mca <民政部导出.json>
python scripts/regions.py --import-villages <统计局村级.csv>
python scripts/regions.py --import-streets <乡镇名.csv>
```

> **缓存不进仓库**（`data/` 已 `.gitignore`）。换机器需要重新抓一次或导入。

## 5. 输入模板

标准输入模板 16 列，是**唯一真源**（`scripts/export.py: TPL_FIELDS`）：

```bash
python scripts/export.py --template assets/模板_采集任务清单.xlsx
```

| 列 | 必填 | 说明 |
|---|---|---|
| 任务ID | 是 | 唯一标识，如 `T001`；同一批不要重复 |
| 任务类型 | 是 | 政府驻地 / POI周边 / POI区内分类 / POI关键词 / 地址转坐标 / 坐标转换 |
| 省 | 按任务类型 | 如「广西壮族自治区」；坐标转换类可留空 |
| 市 | 按任务类型 | 如「南宁市」。**城市限定必带** |
| 区县 | 按任务类型 | 如「青秀区」；无门牌号时至少填到这一级 |
| 乡镇 | 按任务类型 | 如「伶俐镇」；政府驻地类建议填 |
| 关键词 | 按任务类型 | POI 类任务的检索词，如「小学」「加油站」 |
| 中心点经度 / 纬度 | 按任务类型 | 仅 POI周边 用；WGS84 |
| 半径米 | 按任务类型 | 仅 POI周边 用；>2000 自动切网格防漏 |
| 名称 | 按任务类型 | 目标名称（政务网点/机构名），用于辅助互证 |
| 详细地址 | 按任务类型 | **优先按地址查询**，请尽量写全到门牌号 |
| 参考经度 / 纬度 | 否 | 用户已有的参考坐标（用于比对） |
| 待查列 | 按任务类型 | 需要补齐的列，逗号分隔；留空表示查全部 |
| 备注 | 否 | 如「该点有两个同名，请确认是山上那个」 |

**三条填写纪律**：① 城市限定必带，否则同名地点必然误匹配；② 详细地址尽量写到门牌号
（实测有/无门牌号达标率差 14.7 个百分点）；③ 只填待查列，已有值的行不重复查（省配额）。

示例见 [`../examples/示例_地址转坐标.csv`](../examples/示例_地址转坐标.csv)。

## 6. 任务类型与参数

`collect.Job` 字段与任务类型的对应关系：

| 任务类型 | `kind` | 必填字段 | 说明 |
|---|---|---|---|
| 政府驻地 | `gov_seat` | `province` / `city` / `area` / `levels` | `levels=(2,)` 市、`(3,)` 区县、`(4,)` 乡镇；可多级 |
| POI 区内分类 | `poi_area` | `province` / `city` / `area` / `keyword` | 网格切分 + 分页去重，超量自动下钻 |
| POI 周边 | `poi_around` | `center=(lon,lat)` / `radius_m` / `keyword` | 同心圆补采，防半径边缘漏点 |
| 地址转坐标 | `geocode` | `input_file` / `addr_col` | 表格地址列批量地理编码 |
| 坐标转换 | — | — | 直接调 `gc_common` 函数，不走采集引擎 |
| 坐标系侦测 | — | — | `gc_common.detect_crs()`，**只侦测不决断** |

其他常用字段：`sources`（指定源，空=按已配置 Key 自动排序）、`max_items`（0=不限）、
`out_crs`（`WGS84` / `GCJ02`）、`town`（限定乡镇）、`types`（高德 POI 分类码）。

## 7. 跑任务（Python API）

```python
import sys
sys.path.insert(0, "scripts")

from collect import Job, run
from export import build_six_tables, write_table, write_qc_report
```

### 7.1 政府驻地（青秀区全部乡镇）

```python
job = Job(kind="gov_seat", name="青秀区乡镇政府驻地",
          province="广西壮族自治区", city="南宁市", area="青秀区", levels=(4,))
res = run(job)          # 先打印「抓前计划」，再执行；断点落 data/checkpoints/
rows = res["结果"]
print(res["总条数"], res["成功"], res["未命中"], res["耗时秒"])
```

### 7.2 POI 区内分类

```python
job = Job(kind="poi_area", name="青秀区小学",
          province="广西壮族自治区", city="南宁市", area="青秀区", keyword="小学")
res = run(job)
```

### 7.3 POI 周边

```python
job = Job(kind="poi_around", name="民族大道周边加油站",
          center=(108.3622, 22.8199), radius_m=3000, keyword="加油站",
          city="南宁市")
res = run(job)
```

### 7.4 地址转坐标

```python
job = Job(kind="geocode", name="政务网点补坐标",
          input_file="examples/示例_地址转坐标.csv",
          addr_col="详细地址", lon_col="经度", lat_col="纬度")
res = run(job)
```

### 7.5 坐标转换与纠偏（不需要 Key）

```python
import sys
sys.path.insert(0, "scripts")
from gc_common import wgs84_to_gcj02, gcj02_to_wgs84, wgs84_to_bd09, bd09_to_wgs84

glon, glat = wgs84_to_gcj02(108.366543, 22.817765)   # 工程坐标 → 高德坐标
wlon, wlat = gcj02_to_wgs84(glon, glat)              # 六次迭代逆解，误差 <1 m
```

> **禁止**把高德/腾讯/百度的原始坐标直接当 WGS84 用：GCJ-02 偏移在广西实测达 **450 m 量级**。

### 7.6 坐标系侦测

```python
from gc_common import detect_crs

r = detect_crs([(108.366543, 22.817765), (109.413, 24.325)],
               addrs=["南宁市青秀区民族大道100号", "柳州市城中区…"], sample_n=10)
# → {"判定": "WGS84|GCJ-02|无法判定", "置信度": "高|中|低", "样本明细": [...]}
```

侦测结论**必须交用户拍板后再转换**，误判代价 = 整表偏移 500 m。

## 8. 输出六表与质检报告

```python
tables = build_six_tables(rows)          # {"地市表": [...], ..., "校验表": [...]}
write_table("output/六表.xlsx", tables)  # 三级降级：openpyxl → 纯标准库 xlsx → CSV

meta = {"任务ID": res["任务"], "模块": "gov_seat", "条数": res["总条数"],
        "起止": "2026-10-23 09:00~09:04", "版本": "1.1.1",
        "计划请求数": res["计划"].get("预计请求数", 0),
        "实际请求数": res["配额"].get("总请求", 0),
        "计划耗时": res["计划"].get("预计耗时文案", ""),
        "实际耗时": f'{res["耗时秒"]} s'}
write_qc_report("output/质检报告.md", meta, rows)
```

| 产物 | 内容 |
|---|---|
| 六表 `.xlsx` | 地市 / 区县 / 乡镇 / 明细清单 / 汇总表 / 校验表 |
| 降级 `.csv` | 无 openpyxl 时同前缀多文件，列名与内容完全一致 |
| 质检报告 `.md` | 五段固定结构（概览 / 计划对账 / 质量结论 / 异常清单 / 遗留建议） |

明细 20 列必带 `经度_GCJ02 / 纬度_GCJ02`，供用户在高德地图直接取点核对；
`质检状态` 只有 **通过 / 存疑 / 未命中** 三种。

## 9. 断点续传与配额

- 每条结果即时写入 `data/checkpoints/<任务ID>.jsonl`；中断后 `run(job)` 默认
  `resume=True`，自动跳过已完成键，**已花钱的调用不重复**。
- 计划阶段的「各源配额占用」会与实际日用量对账；超日配额直接告警给分批建议。
- 日配额爆掉 → **当日熔断**，已跑部分落盘，不空转重试；跨自然日不盲重试。
- 想重跑整批：`run(job, resume=False)` 或删除对应断点文件。

## 10. 交付前自查

- [ ] 六表与质检报告都已生成，质检状态只有三种取值
- [ ] 每条输入都有输出行（必填满），未命中给了原因与建议动作
- [ ] 质检报告「计划对账」里的请求数与实际用量一致
- [ ] 需要人工确认的条目已单列，并附 GCJ-02 坐标
- [ ] 未覆盖用户原文件（模板回填输出到新文件）
