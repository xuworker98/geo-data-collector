# examples

示例输入表，只用于演示**格式**，不是真实业务数据。

| 文件 | 说明 |
|---|---|
| `示例_地址转坐标.csv` | 标准输入模板 16 列的最小示例，含地址转坐标 / POI 关键词 / 坐标转换 / 政府驻地 / POI 周边 五类任务 |

使用方式：

```bash
python scripts/export.py --template assets/模板_采集任务清单.xlsx   # 生成带填写说明的 xlsx 模板
```

- 输入 CSV 支持自动编码侦测（`utf-8-sig → gbk → gb18030 → utf-8`）
- 正式任务建议用 xlsx 模板填写，`填写说明` sheet 里有逐列规则
- 示例中的地址取自输入模板，仅供演示；实际任务请填真实、写到门牌号的地址
